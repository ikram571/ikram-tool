🔑 1)  KEY

When the tool first opens, it will ask:

   🔑 Enter key:

Type this EXACTLY:

   FREETOOL

Then press ENTER.
The tool says "Tool unlocked!" and opens. ✅
(Every version uses the same key — FREE! 💯)

📂 2) THE FOLDERS (VERY IMPORTANT)

In your IKRAM TOOL folder you will see:

   📥 DROP        = put your INPUT files here
   📤 RESULT      = your OUTPUT files appear here

Inside DROP:
   ├─ pak/     ➜ put your .pak game files here
   ├─ lua/     ➜ put your .lua files here
   └─ inject/  ➜ put files you want to inject here

Inside RESULT:
   ├─ extracted/  ➜ files after you UNPACK a pak
   ├─ injected/   ➜ files after you INJECT
   ├─ lua/        ➜ files after COMPILE / DECOMPILE
   ├─ CostomPak/  ➜ the pak you build with COSTOM PAK
   ├─ Repacked/   ➜ the pak you get after REPACK
   └─ processed/  ➜ other processed files

Rule 📌: DROP = in, RESULT = out. Easy!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📦 3) PAK TOOL — all 4 options

Press 1 in the main menu to open PAK TOOL.

➡️ OPTION 1 — UNPACK PAK
   • Put your .pak in DROP/pak
   • Pick it from the list, press ENTER
   • Wait — it unpacks
   • 👍 RESULT: look in RESULT/extracted

➡️ OPTION 2 — INJECT FILE
   • Put the file you want to add in DROP/inject
   • The tool asks where to put it in the pak
   • Pick a folder number or press ENTER for auto
   • 👍 RESULT: the modified pak is saved

➡️ OPTION 3 — REPACK PAK
   • First UNPACK a pak (option 1)
   • Edit the files in RESULT/extracted
   • Pick the pak again and it rebuilds it
   • 👍 RESULT: your finished pak is in
     RESULT/Repacked/  ✅
   • Your original .pak in DROP is NEVER
     changed or overwritten. 🔒

➡️ OPTION 4 — COSTOM PAK
   • Pick a source pak in DROP/pak
   • Press ENTER without typing → builds a
     pak with ALL folders + all file names,
     but every file EMPTY (0 bytes) — this
     pak works in the real game once you
     inject files into it. 🧩
   • Pick a folder number → ONLY that folder
     chain goes in, and its files are
     COPIED real (not empty).
   • Type your own path → ONLY that path,
     and every file under it copied real.
   • 👍 RESULT: RESULT/CostomPak/

💡 TIP: long paks take a little time —
    just wait for the green ✔ message. ⏳

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📜 4) LUA TOOL — compile & decompile

Press 2 in the main menu to open LUA TOOL.

➡️ OPTION 1 — COMPILE (+ PROTECT)
   • Put your .lua source in DROP/lua
   • Pick the file, press ENTER
   • Makes a compiled + protected working file
   • 👍 RESULT: RESULT/lua/

➡️ OPTION 2 — DECOMPILE
   • Put a compiled .lua in DROP/lua
   • Pick the file, press ENTER
   • Makes readable source code from it
   • 👍 RESULT: RESULT/lua/ (name_GAME.lua)

⚠️ NOTE: if a file is fully DECRYPTED /
   PROPERLY ENCRYPTED by its owner, the tool
   honestly says "This file is encrypted and
   can't be decompiled by this tool." That is
   NOT an error — it means the file's code was
   locked by the modder and cannot be read. 🔒
   (No *GAME.lua file is created for it.)

🚀 5) HOW TO INSTALL & RUN

🔸 INSTALL (in Termux):
   Open Termux and paste:

      bash install.sh

   Wait until it finishes. (It downloads the
   latest version automatically.)

🔸 Or download the zip here:
   https://github.com/ikram571/ikram-tool/releases/latest/download/IkramTool.zip

🔸 RUN:
   In Termux folder of the tool, type:

      bash run.sh

   (After install you can also just type:  ikram )

🔸 PROJECT / REPO:
   https://github.com/ikram571/ikram-tool
