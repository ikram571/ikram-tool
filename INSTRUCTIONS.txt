📂 2) THE FOLDERS (VERY IMPORTANT)

In your IKRAM TOOL folder you will see:

   📥 DROP        = put your INPUT files here
   📤 RESULT      = your OUTPUT files appear here

Inside DROP (LOWERCASE — case matters!):
   ├─ pak/     ➜ put your .pak game files here
   ├─ lua/     ➜ put your .lua / .luac files here
   └─ inject/  ➜ files you want to inject or pack

Inside RESULT:
   ├─ extracted/   ➜ files after you UNPACK (edit here)
   ├─ processed/   ➜ unpack sidecar copies
   ├─ injected/    ➜ <name>.pak after you INJECT
   ├─ Repacked/    ➜ <name>.pak after you REPACK
   ├─ CostomPak/   ➜ <name>.pak after COSTOM PAK
   └─ lua/         ➜ .luac, .lua or .FAILED.txt

Rule 📌: DROP = in, RESULT = out. Easy!
(You never have to type or choose anything by
hand — the tool lists the files for you.)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📦 3) PAK TOOL — 4 operations

Press 1 in the main menu to open PAK TOOL.

➡️ OPTION 1 — UNPACK
   • Put your .pak in DROP/pak
   • Press 1, then press Y to PROCEED
   • Wait — live progress is shown
   • 👍 RESULT: RESULT/extracted/<name>/

➡️ OPTION 2 — INJECT
   • Put the file(s) to add in DROP/inject
   • Put the target .pak in DROP/pak
   • Press 2 — select the pak, then choose a mode:
     1 = INJECT ONE FILE (pick its path)
     2 = INJECT ALL — auto-put (only asks for
         the new file's path)
   • 👍 RESULT: RESULT/injected/<name>.pak

➡️ OPTION 3 — REPACK
   • First UNPACK a pak (option 1)
   • Edit the files in RESULT/extracted/<name>/
   • Press 3, choose the extracted folder + DROP/pak
   • 👍 RESULT: RESULT/Repacked/<name>.pak
   • Your original .pak in DROP is NEVER
     changed or overwritten. 🔒
   • If RESULT/Repacked/<name>.pak already exists,
     it gets overwritten (this folder is the only one).

➡️ OPTION 4 — COSTOM PAK
   • Press 4, choose the extracted folder
   • A new pak skeleton is created
   • 👍 RESULT: RESULT/CostomPak/<name>.pak

💡 TIP: long paks take a little time —
   just wait for the box to finish. ⏳
   (C = clear DROP/pak, R = clear RESULT.)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📜 4) LUA TOOL — 2 operations

Press 2 in the main menu to open LUA TOOL.

➡️ OPTION 1 — COMPILE
   • Put your .lua source in DROP/lua
   • Press 1, then press Y to PROCEED
   • Makes a compiled + protected .luac
   • 👍 RESULT: RESULT/lua/

➡️ OPTION 2 — DECOMPILE
   • Put a compiled .luac in DROP/lua
   • Press 2, then press Y to PROCEED
   • The tool first detects the file's format and
     encryption level, then tries every decompiler
     and keeps the most readable output
   • 👍 SUCCESS: RESULT/lua/<name>_decompiled.lua
     + quality score (Excellent/Poor)
   • 👍 LOCKED: RESULT/lua/<name>_FAILED.txt —
     it says exactly why the file could not be
     opened (properly encrypted / locked by owner).
     This is NOT an error — the file is just sealed. 🔒

🚀 6) HOW TO INSTALL & RUN

🔸 INSTALL (in Termux):
   Open Termux and paste:

      curl -fL https://cdn.jsdelivr.net/gh/ikram571/ikram-tool@main/install.sh | bash

   Wait until it finishes. (It downloads the
   latest version automatically.)

🔸 Or download the zip here:
   https://github.com/ikram571/ikram-tool/releases/latest/download/IkramTool.zip

🔸 RUN:
   In the tool's Termux folder, type:

      bash run.sh

   (After install you can also just type:  ikram )
